Owner login

Anyone can view this log. Only you can change it, using a GitHub token that is saved in this browser only.

  1. Create a fine-grained token.
  2. Under "Repository access", choose "Only select repositories" and pick this repo.
  3. Under "Permissions", set Contents to "Read and write". Choose the longest expiry.
  4. Generate it and paste it below.

You're logged in as owner on this device. Changes are saved to and shown to everyone within about a minute.
